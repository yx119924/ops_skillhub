## 编写提示

### 部署文档模板建议章节

1. **概述**：系统用途、依赖、负责人
2. **环境要求**：操作系统、依赖软件、网络端口
3. **部署步骤**：每一步具体命令
4. **配置说明**：配置项、默认值、含义
5. **验证步骤**：部署后如何确认成功
6. **回滚方案**：如何回滚到上一版本
7. **常见问题**：FAQ

### 部署脚本规范

- **幂等性**：重复执行结果一致
- **可逆性**：每个变更都有回滚路径
- **可观测性**：关键步骤有日志输出
- **环境隔离**：dev/test/prod 严格区分
- **dry-run**：先模拟再执行
